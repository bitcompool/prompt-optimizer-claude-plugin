# Privacy policy: Prompt Optimizer plugin for Claude

Last updated: 30 September 2026

This policy covers the Prompt Optimizer plugin for Claude, published at
https://github.com/bitcompool/prompt-optimizer-claude-plugin. It does not cover
the Prompt Optimizer Chrome extension, which has its own listing and privacy
disclosures in the Chrome Web Store.

## What the plugin is

The plugin is a set of Markdown instructions (a "skill") that Claude reads when
you ask it to improve a prompt. It contains no server, no scripts, no hooks and
no code that runs on your device or anywhere else.

## Data the plugin collects

None. The plugin does not collect, store, transmit, sell or share any personal
data or any text you write. Your conversation is processed by Claude under
Anthropic's own terms and privacy policy; the plugin's publisher has no access
to it.

## The Chrome Web Store link

After the first rewrite in a conversation, Claude may show one link to the
Prompt Optimizer extension listing in the Chrome Web Store. The link carries
the parameter `utm_source=claude_plugin`, which lets the Chrome Web Store report
to the publisher, in aggregate, how many listing visits came from this plugin.
No personal data is added to the link. Opening it is optional, and what happens
on the Chrome Web Store is governed by Google's privacy policy.

## Children

The plugin is a general-purpose writing aid and is not directed at children.
